# Tools vbot

Telegram-бот для генерации QR-кодов, преобразования текста в Base64 и работы с фотографиями, стикерами и премиум-эмодзи.

## Команды

| Команда | Что делает |
| --- | --- |
| `/start` | Открывает меню бота. |
| `/qr https://example.com` | Создаёт QR-код в PNG из текста или ссылки. |
| `/enc64 Привет` | Кодирует текст UTF-8 в Base64. |
| `/dec64 0J/RgNC40LLQtdGC` | Декодирует Base64 обратно в текст UTF-8. |

В личном чате отправь боту фото, стикер или сообщение с премиум-эмодзи.

- **Фото** — кнопка «Ссылка» загружает его на [x0.at](https://x0.at/) и возвращает ссылку. Кнопка «GIF» создаёт пятисекундный MP4 без звука и отправляет его как анимацию Telegram.
- **Стикер** — бот возвращает его `file_id`.
- **Премиум-эмодзи** — бот показывает идентификаторы `custom_emoji_id`.

В группе ответь на сообщение с фото, стикером или премиум-эмодзи и упомяни бота по его имени, например `@your_bot`.

## Локальный запуск

Нужен Python 3.10 или новее. Для преобразования фото в анимацию установи FFmpeg с кодеком `libx264` и добавь его в `PATH`.

```bash
git clone https://github.com/vvevop/tools_vbot.git
cd tools_vbot
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt Pillow
```

Получив токен у [@BotFather](https://t.me/BotFather), создай в корне проекта файл `.env`:

```dotenv
BOT_TOKEN=токен_бота
```

Запусти бота из корня проекта:

```bash
python main.py
```

Бот получает обновления через long polling. При запуске он удаляет настроенный webhook и сбрасывает накопленные обновления.
